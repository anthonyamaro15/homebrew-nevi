# Homebrew Tap for Nevi

Install Nevi with Homebrew:

```bash
brew install anthonyamaro15/nevi/nevi
```

Or tap first:

```bash
brew tap anthonyamaro15/nevi
brew install nevi
```

Update Nevi after a new release:

```bash
brew update
brew upgrade nevi
```

Verify the installed binary:

```bash
nevi --version
```

Nevi creates its user config files on first launch:

```text
~/.config/nevi/config.toml
~/.config/nevi/languages.toml
```
